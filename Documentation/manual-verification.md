# 実機での確認手順

この環境では画面収録も Accessibility も使えず、描画・ドラッグ・Finder の実挙動は
自動化できない(`CGWindowList` でウインドウの存在は見られるが中身は見えない)。
自動テストで押さえられない事だけをここに集める。各項目は **手順 → 期待** の形。
確認できたら日付を入れて設計書 §12 / §10 に反映する。

前提: `xcodebuild -scheme KaitoFinder build` した `KaitoFinder.app` を使う。
テスト用の書庫は `inbox/` に置く(`.gitignore` 済み)。

## 1. Finder は directory promise を満たすか(設計書 §12-1)

1. 中にフォルダを含む ZIP を開き、そのフォルダを Finder のウインドウへドラッグする。
2. **期待**: フォルダごと展開され、中身が揃う。進捗シートが出て、取り消しで途中の物が残らない。
3. 満たさない場合(空フォルダだけ出来る・何も起きない)は §12-1 の代替経路
   (展開済み temp を渡す)へ切り替える。

## 2. quarantine の伝播(設計書 §12-2)

1. Safari で ZIP をダウンロードし、`xattr -p com.apple.quarantine <zip>` で印を確かめる。
2. KaitoFinder で開き、ファイルを一つ Finder へドラッグ、もう一つを ⌘C → Finder で ⌘V。
3. **期待**: 両方に `com.apple.quarantine` が付く(`xattr -p` で書庫と同じ agent 名)。
4. ローカルで作ったファイル(印なし)を ⌘N で書庫にする。
5. **期待**: 出来た書庫に印が **付かない**(`xattr -l` が空)。
6. 印付きのファイルを含めて ⌘N で書庫にする。**期待**: 書庫に印が付く。

## 3. 暗号化書庫

1. `zip -P secret` で作った ZIP を開く。**期待**: 一覧は出て、ファイルをドラッグした時に初めてパスワードを聞かれる。
2. 間違ったパスワード → 「パスワードが違います」で再入力。正しい → 展開される。
3. 「このパスワードを記憶」を付けて入力後、閉じて開き直しドラッグ。**期待**: 聞かれない。
4. 編集 › 記憶したパスワードをすべて削除 → 開き直しドラッグ。**期待**: また聞かれる。
5. `7zz a -p... -mhe=on` の 7z を開く。**期待**: 一覧の代わりに鍵付きの画面が出て、解除後に一覧。

## 4. 書庫内編集と取り消し

1. ZIP に Finder からフォルダをドロップ → 一覧に増える。⌘Z → 消える。⇧⌘Z → 戻る。
2. 名前をクリックして改名。空・`/` 入り・既存名 → 拒否されて編集が続く。Esc → 取消。
3. tar / tar.gz / 7z / lzh でも 1 を行う。**期待**: 通知欄に「編集すると書庫全体を再圧縮します」。
4. RAR を開く。**期待**: 「RAR 書庫は変更できません」と表示される。ファイルのドロップにはハイライトが出る。
5. 4 の RAR にドロップ。**期待**: 変換の確認が出て、選んだ形式の新しい書庫が開く。原本のウインドウも残る。
6. 同じ書庫ウインドウで複数項目を別フォルダ（ファイル上ならその親）へドラッグ。**期待**: 通常は「+」なしで移動して移動先が展開・選択され、⌥ では「+」付きコピー。同じ親・自分自身・自分の子孫への移動は不可、名前衝突は理由を表示して全項目が不変。⌘Z の「移動」一回で全項目が戻り、⇧⌘Z で再移動する。別書庫へのドラッグはコピーのまま。

## 5. 表示

1. 検索欄に「ｼｬｼﾝ」→ 「写真」ではなく「シャシン」「しゃしん」以外の半角/全角違いだけが揃う(かなは畳まない)。
2. Space でクイックルック、ダブルクリックで既定アプリ、右クリック › このアプリケーションで開く。
3. 検索欄がツールバー(ウインドウ上部、unified)にある。入力で一覧が絞られる。
4. パスバー(一覧の下): 何も選ばないと書庫名だけ。深い項目を選ぶと「書庫名 › フォルダ › … › 項目」。
   途中のフォルダを click → そのフォルダが選択され、一覧がそこへ scroll する。書庫名を click → 選択解除。
5. 画像を含む書庫(PNG / JPEG、8 MiB 以下)を開く。**期待**: 名前列のアイコンが少し遅れてサムネイルに置き換わる。
   暗号化された画像・8 MiB 超・テキストは通常のアイコンのまま。パスワードを聞かれない。
6. システム設定 › デスクトップとDock › 「書類を開くときはタブで開く」を「常に」にして 2 つの書庫を開く。
   **期待**: 一つのウインドウのタブになり、ウインドウメニューに「すべてのウインドウを結合」等が出る。
7. 一覧の最終行より下の空白部分を右クリックする（空の書庫でも行う）。**期待**: 「新規フォルダ」「ペースト」、区切り、「すべて展開…」、区切り、「新規書庫…」「書庫を Finder に表示」がこの順で出る。「書庫を Finder に表示」で元の書庫が Finder で選択される。未選択の行を右クリックするとその行が選択され、行用メニューが出る。
8. ツールバーが「展開」「追加…」「新規フォルダ」「削除」「クイックルック」、伸縮スペース、「検索」の順であることを確認し、ファイル選択・選択解除・フォルダ選択を切り替える。**期待**: 削除は選択時、クイックルックは読めるファイルの選択時に有効。展開は未選択なら全項目、選択時は選択項目を対象にする。読み取り専用書庫では新規フォルダ・削除が無効になり理由が表示され、追加…・ペーストは変換提案に進める。処理中は対応するボタンが無効になる。
9. ツールバーを右クリックしてカスタマイズを開き、ボタンの並べ替え・追加・削除を行う。**期待**: 配置を変更でき、書庫を閉じて開き直しても保持される。既定の構成へ戻すと 8 の順になる。検索欄の入力で一覧が絞られる。

## 6. Finder のサービス

1. Finder で複数ファイルを選び、右クリック › サービス(または「クイックアクション」) › 「KaitoFinderで圧縮」。
2. **期待**: 保存パネル(形式の選択付き)→ 進捗 → 出来た書庫が KaitoFinder で開く。
3. **期待**: Finder 以外のアプリのサービスには出ない。必要ならシステム設定 › キーボード › キーボードショートカット › サービスで有効にする。
4. **期待**: 保存パネルで tar.gz を選ぶと、名前が `.tar.gz` のまま保存される(`.tgz` が付け足されない)。
5. Finder›複数のアーカイブを選択›サービス›「KaitoFinderで展開」(英語では「Extract with KaitoFinder」)。
   **期待**: 文書ウインドウを開かず、設定のフォルダ規則どおりに順番に展開される。
   一つの最上位フォルダを持つZIP、最上位に複数ファイルを持つZIP、tar.gzで三つの規則を確認する。
   同名の出力フォルダがあれば「名前 2」「名前 3」と増え、既存の内容を上書きしない。
6. ファイル›「アーカイブを展開…」でも複数を選ぶ。**期待**: アーカイブだけを選択でき、5と同じ動作になる。
   設定の展開先を「毎回確認」にすると、全体で一度だけフォルダを尋ねる。
7. 暗号化されたZIPとヘッダーも暗号化した7zを混ぜる。**期待**: 進捗パネル上でアーカイブ名付きの
   パスワード入力が出る。誤入力は再入力、入力の「キャンセル」はその一つだけを飛ばして次へ進む。
   記憶したパスワードは自動で使い、「このパスワードを記憶」は展開成功後だけ保存する。
8. 大きいアーカイブを二つ以上選び、二つ目の処理中に進捗パネルの「キャンセル」を押す。
   **期待**: 全体が止まり、途中のアーカイブの出力が残らない。一つ目の出力は完全なまま残る。
9. 破損したアーカイブを混ぜる。**期待**: ほかは展開され、最後に失敗数・名前・理由を一つのアラートに表示する。
   すべて成功した場合はアラートを出さず、Finderで出力先を表示することもない。
10. ゴミ箱移動を有効にする。**期待**: 展開成功した原本だけがゴミ箱へ移り、失敗した原本は残る。
    原本の移動に失敗した場合も出力は残り、理由を最終アラートに表示する。
11. 一括展開中に同じサービスやファイルメニューを再度実行する。**期待**: 一括展開は重複起動せず、
    サービスは操作の完了を待つように案内する。完了後は再度実行できる。

## 7. 設定

1. アプリメニューの「設定…」または ⌘, を押す。**期待**: 一般 / 圧縮 / 展開のタブがある
   サイズ固定の設定ウインドウが開く。閉じて再度 ⌘, を押しても、同じウインドウが再利用される。
2. 圧縮 › ZIP › 圧縮方式を「無圧縮」にし、繰り返し文字を含むテキストファイルを ⌘N で ZIP にする。
   `unzip -v <作成した書庫.zip>` を実行する。**期待**: Method 欄が `Stored` になる。
3. 圧縮方式を Deflate、圧縮レベルを 6 に戻し、同じファイルで新しい ZIP を作る。
   **期待**: `unzip -v` で圧縮され、元のサイズより小さくなる。
4. 一般で既定形式を変更して新規作成の保存パネルを開く。**期待**: 同じ形式が選ばれ、
   保存パネルで形式を切り替えると設定画面にも反映される。アプリを再起動しても保持される。
5. 圧縮・展開の各設定を変更し、再起動する。**期待**: すべての値とレベルの数字が保持される。
   展開タブの値は§6の一括展開に反映される。確認後は変更した設定を元へ戻す。

## 8. 新規書庫と変換(M6)

1. 文書がない状態でファイル › 新規書庫…(⌘N)。ファイル二つと子フォルダを含むフォルダを選ぶ。
2. 保存パネルの ZIP / tar / tar.gz / 7z / LHA を順に選ぶ。**期待**: 名前の拡張子が切り替わり、「暗号化はできません」が常に見える。次の作成では最後の形式が選択される。
3. 大きいファイルで作成する。**期待**: 中央の進捗パネルに「書庫を作成しています」、取消ボタン、項目数が出る。完了するとパネルが消え、新しい書庫が開く。
4. 既存の保存先への置換を選び、進捗を取り消す。**期待**: 保存先の byte は変わらず、隣に `.KaitoFinder-new-*` が残らない。取り消さずに完了した場合は新しい書庫へ置き換わる。
5. RAR / CAB / ISO / tar.bz2 / SFX ZIP を開き、Finder からファイルを drop、または Finder でコピーして ⌘V。**期待**: 元の形式名を含む変換の確認が出る。キャンセルで何も変わらない。
6. 暗号化された 7z でも 5 を行う。**期待**: 新しい書庫は暗号化されないという段落が追加される。承諾後、必要なら既存のパスワード入力が出て、その後に保存パネルが出る。
7. 変換を完了する。**期待**: 追加分と元の全項目を読める新規書庫が開く。原本の SHA-256 とウインドウは変わらず、原本自身を保存先に選ぶと拒否される。元の書庫に quarantine があれば新規書庫にも伝わる。
8. 別の KaitoFinder の書庫から読み取り専用書庫へフォルダをドラッグする。**期待**: file promise が受信され、変換の保存先をゆっくり選んでも中身が保持される。確認・パスワード・保存先の各段階で取り消しても原本は変わらない。
