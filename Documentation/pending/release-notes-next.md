# 次版の release notes 下書き（2026-09-29 時点）

`Documentation/releases/<version>.md` を書くときの材料。公開済みの版の notes は編集しない。KaitoKit / GyoshukuKit の版番号は release 時に埋める。

## 修正

- 7z のヘッダ暗号化の判定が I/O エラーなどで失敗したとき、「暗号化なし」と誤って扱わなくなりました。開くときはエラーとして開けず、保存後の再読込では保存前の設定を維持します。
- 分割アーカイブの保存を公開前に取り消したとき、取り消しをそのまま報告し、再ハッシュや保存失敗への読み替えをしなくなりました。証明済みの巻き戻しの後は、取り消された操作からでも再試行できます。
- 未完了の作業台帳の稀なエラー文言が「POSIX <番号>: <説明>」の形になりました。
- 展開を途中で終えた経路で報告する進捗の件数を見直しました。

## 対応形式（次回の KaitoKit / GyoshukuKit の更新で）

- 圧縮された単一ファイルのうち `.taz` は `.tar.Z` と同じ扱いになり、単一項目として表示するときの名前が `x.taz` から `x.tar` になります。`.tar.bz` の扱いは変わりません。
- 保存中に作る一時ファイルは名前を持たなくなり、保存先のフォルダに `.gyoshuku-` で始まる隠しファイルが現れなくなりました。
