# KaitoFinder 0.10.4

NAS などネットワーク上のアーカイブを読む速さを改善しました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.16.0 / GyoshukuKit 0.13.0 / Sparkle 2.10.0 を同梱。

## 改善

- ネットワーク共有など、ローカルでないボリューム上のアーカイブを、往復に時間のかかる入力として扱うようにしました（KaitoKit 0.16.0）。
  - solid の 7z（LZMA2）では、最初の項目を読む前の全体の走査を省き、プレビューや展開を早く始めます。走査は次の読み取りで時間を区切って行い、遅ければ打ち切ります。
  - RAR4 / RAR5 の一覧の読み込みで、ヘッダをまとめて読み、ネットワーク越しの往復を減らしました。
  - 分割 RAR の 2 巻目以降を単独で開いたときは、多くの場合、全体を読む前に開けないことを知らせます。メッセージは従来と同じです。
- ローカルのディスク上のアーカイブから読み取れる内容と、アーカイブの作成・更新の動作は 0.10.3 と同じです。GyoshukuKit 0.13.0 は KaitoKit 0.16.0 への追従だけの更新です。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開ができなくなることがあります。以前の版からある問題で、ウインドウを開き直すと直ります。今後の版で修正します。

## English

Faster reading of archives on NAS and other network volumes. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.16.0 / GyoshukuKit 0.13.0 / Sparkle 2.10.0.

### Improved

- Archives on non-local volumes, such as network shares, are now treated as high-latency input (KaitoKit 0.16.0).
  - For solid 7z (LZMA2) archives, the full scan before reading the first item is skipped, so preview and extraction start sooner. The scan runs on a later read with a time limit and stops if it is slow.
  - Listing RAR4 / RAR5 archives reads headers in larger batches, reducing round trips over the network.
  - Opening the second or a later volume of a split RAR on its own is now usually reported as unopenable before the whole file is read. The message is unchanged.
- What is read from archives on local disks, and creating or updating archives behave as in 0.10.3. GyoshukuKit 0.13.0 only follows KaitoKit 0.16.0.

### Known issue

- After an open archive is renamed or moved in Finder or elsewhere, preview, Quick Look and extraction in its window may stop working. This problem predates this version; reopening the window fixes it. It will be fixed in a future version.
