# KaitoFinder 0.10.7

書庫の対応形式を拡げました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.19.0 / GyoshukuKit 0.16.0 / Sparkle 2.10.1 を同梱。

## 改善

- **7z と XZ の RISC-V フィルター付き書庫を展開できるようになりました。** JAL、AUIPC と後続命令の対、圧縮命令を含む入力に対応します。
- **RAR4 / RAR5 の分割自己解凍書庫に対応しました。** `.partN.exe`、RAR4の `.exe` / `.r00` 形式も開けます。
- **KaitoKit が RAR5 compression version 1 に対応しました。** 80 distance symbols と 4 GiB を超える非2の累乗辞書を扱えます。version 1 の辞書は次の2の累乗で確保するため、出力と実確保量に応じた上限が必要です（5 GiB 辞書は 8 GiB）。

アプリの操作方法、編集・保存の仕組みは 0.10.6 と同じです。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開が
  できなくなることがあります。以前の版からある問題で、ウインドウを開き直すと直ります。今後の版で修正します。
- アプリのコーデック辞書の上限は 1 GiB です。RAR5 compression version 1 の書庫のうち、これを超える実確保量が必要なものは
  現行のアプリ設定では展開できません。KaitoKit の API で上限を引き上げた場合の対応であり、アプリ側の上限緩和は今後の課題です。

## English

Expanded the range of supported archive variants. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.19.0 / GyoshukuKit 0.16.0 / Sparkle 2.10.1.

### Improvements

- Extract 7z and XZ archives that use the RISC-V filter, including JAL, AUIPC pairs and compressed instructions.
- Open RAR4 / RAR5 split self-extracting archives, including `.partN.exe` and RAR4 `.exe` / `.r00` layouts.
- KaitoKit now decodes RAR5 compression version 1 with 80 distance symbols and non-power-of-two dictionaries above 4 GiB. Version 1 dictionaries use the next power-of-two allocation, so limits must cover both the output and actual allocation (5 GiB becomes 8 GiB).

The user interface and editing / saving model are unchanged from 0.10.6.

### Known issues

- After an open archive is renamed or moved in Finder or elsewhere, preview, Quick Look and extraction in its window
  may stop working. This problem predates this version; reopening the window fixes it. It will be fixed in a future version.
- The app's codec dictionary limit is 1 GiB. RAR5 compression version 1 archives that need a larger allocation cannot be extracted
  with the current app settings. KaitoKit supports them when its API limits are raised; relaxing the app's limit remains future work.
