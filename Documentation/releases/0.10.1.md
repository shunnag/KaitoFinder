# KaitoFinder 0.10.1

設定と保存パネルの文言を、26 言語すべてで macOS の表記にそろえました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.14.1 / GyoshukuKit 0.11.0 / Sparkle 2.10.0 を同梱。

## 変更

- 日本語の「標準に戻す」を「デフォルトに戻す」に、メニューの「（標準）」を「（デフォルト）」に、「新規アーカイブの既定フォーマット」を「新規アーカイブのデフォルトフォーマット」に変更しました。macOS の表記に合わせたものです。圧縮レベルの「標準」はそのままです。
- 保存パネルの「フォーマット」「圧縮レベル」「フィルタ」の行ラベルにもコロンを付け、ほかの行とそろえました。設定の 7z タブの「フィルタ」も同じです。VoiceOver の読み上げは変わりません。
- 各言語で、「デフォルトに戻す」、デフォルトの印、アーカイブユーティリティ、低電力モードなどの訳を Apple の表記に合わせました。ロシア語とフランス語では「デフォルトに戻す」ボタンが短くなりました。
- 各言語で、「アーカイブ」「分割アーカイブ」などの訳語の揺れをそろえました。
- デンマーク語とノルウェー語の保存ボタンが「アーカイブする」と読める訳になっていた問題を修正しました。
- tar.xz の説明のメモリ量を、実際の値（デフォルトのレベルで 1 スレッドあたり約 135 MB）に直しました。レベルを上げるとさらに増えることも説明に加えました。
- 日本語と中国語のツールチップで、文と文のあいだに余分な空白が入っていた問題を修正しました。

## English

Settings and the save panel now use macOS wording consistently in all 26 languages. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.14.1 / GyoshukuKit 0.11.0 / Sparkle 2.10.0.

### Changed

- In Japanese, the Restore Defaults button, the default marker in menus, and the default format setting now use the same word for “default” as macOS.
- The Format, Compression Level, and Filter rows in the save panel now end with a colon like the other rows, as does the Filter row in the 7z settings tab. VoiceOver labels are unchanged.
- Restore Defaults, the default marker, Archive Utility, Low Power Mode, and similar terms now match Apple's translations in each language. The Restore Defaults button is shorter in Russian and French.
- Terms for archives and split archives are now consistent within each language.
- In Danish and Norwegian, the Save button no longer reads as “Archive”.
- The tar.xz description now gives the measured memory use (about 135 MB per thread at the default level) and notes that higher levels use more.
- Tooltips in Japanese and Chinese no longer put an extra space between sentences.
