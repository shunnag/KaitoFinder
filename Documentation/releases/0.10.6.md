# KaitoFinder 0.10.6

アーカイブの読み取り・書き込みエンジンを更新し、開く・一覧する・展開する・圧縮する処理を速くしました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.18.0 / GyoshukuKit 0.15.0 / Sparkle 2.10.1 を同梱。

## 改善

- **書庫を開く・一覧する処理を高速化しました。** 名前の文字コード判定、ZIP64、tar / LHA / RAR のヘッダー走査、ネットワークボリュームからの読み取りを改善しました。
- **多くの圧縮方式で展開を高速化しました。** ライブラリの計測例では、RAR5 の solid 書庫（JPEG 72枚）が 233 → 58 ms、LZMA 圧縮の DMG が 7.4 → 0.46 秒、WinZip AES の小さなファイル 2,000 件が 1.43 → 0.05 秒です。
- **ZIP・7z・暗号化書庫の書き込みを改善しました。** ZIP AES の鍵導出と暗号化、7z の一括追加、tar の出力バッファーを効率化しました。ZIP では、圧縮済みファイルを無圧縮で格納する設定の対象に AVIF / JXL / HEIF / EPUB / Office 文書などを追加しました。
- **圧縮 tar と単一ファイルの一時展開を効率化しました。** 展開後の大きさが分かる形式では、必要な領域だけを使い、メモリ使用量と読み書きを減らしました。

アプリの操作方法、対応形式、編集・保存の仕組みは 0.10.5 と同じです。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開が
  できなくなることがあります。以前の版からある問題で、ウインドウを開き直すと直ります。今後の版で修正します。

## English

Updated the archive reading and writing engines to improve opening, listing, extraction and compression performance. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.18.0 / GyoshukuKit 0.15.0 / Sparkle 2.10.1.

### Improvements

- Faster archive opening and listing through improvements to filename-encoding detection, ZIP64, tar / LHA / RAR header scanning and reads from network volumes.
- Faster extraction across many codecs. Library measurements include RAR5 solid archives (72 JPEGs) at 233 → 58 ms, LZMA-compressed DMGs at 7.4 → 0.46 seconds, and 2,000 small WinZip AES entries at 1.43 → 0.05 seconds.
- Faster ZIP / 7z and encrypted-archive writing, including WinZip AES key derivation and encryption, 7z batch additions and buffered tar output. ZIP also recognizes more already-compressed types, including AVIF / JXL / HEIF / EPUB / Office documents, when storing compressed files without recompression is enabled.
- Lower memory use and I/O when staging compressed tar and standalone compressed files with a known expanded size.

The user interface, supported formats and editing / saving model are unchanged from 0.10.5.

### Known issue

- After an open archive is renamed or moved in Finder or elsewhere, preview, Quick Look and extraction in its window
  may stop working. This problem predates this version; reopening the window fixes it. It will be fixed in a future version.
