# KaitoFinder 0.2.0

KaitoKit 0.8.0 の形式追加と修正に対応しました。macOS 26 以降、Apple Silicon 専用。

## できること

- Apple Disk Image（DMG）、UDF、WIM、Compound File（MSI など）、CHM、ARJ の閲覧・展開・プレビュー。
- MacBinary、AppleSingle、BinHex、lzip、Brotli、pbzx の閲覧・展開・プレビュー。
- ZIP の旧方式 Shrink / Reduce 1〜4 / Implode と、7z の Zstandard coder の展開・プレビュー。
- `.tar.lz` / `.tar.br` の中身を tar として一覧・展開。

## 更新

- KaitoKit 0.8.0 由来の 7z BCJ / ARM64 filter の修正、RAR5 file copy、GNU sparse tar（pax 0.0 / 0.1 / 1.0）、ISO の zisofs 読み取りを反映しました。使用する KaitoKit には 0.8.1 のリリースレビュー修正も含みます。
- Finder 製 ZIP の一覧は 0.1.0 と同じです。`__MACOSX` 内の付随ファイルを保持し、表示と削除で同じ項目番号を使います。
- 新形式を「開く」、展開サービス、一括展開パネル、ようこそ画面のドロップに接続しました。ディスクイメージと旧 Mac 形式は macOS 標準の開き手を尊重する関連付けです。
- 一覧だけが可能な未対応方式の項目は、プレビュー・外部アプリケーションで開く操作を無効にします。

## 注意

- 新たに追加した形式と `.tar.lz` / `.tar.br` は読み取り専用です。新規作成・編集できる形式は従来どおりです。
- DMG の ADC / APFS / decmpfs、WIM の solid / LZMS・他巻の内容・EFS、ARJ の method 4・garbled・分割の続きなどは展開できません。ISO の zisofs2 / multi-extent zisofs、tar の旧 GNU `S` 型・star sparse にも未対応です。
- Office / Outlook の文書拡張子と、拡張子のない pbzx Payload は関連付けません。内容を調べる場合は「ファイル > 開く…」を使ってください。
- 圧縮 tar は開くときに一時展開します。大きな書庫では空き容量に注意してください。
