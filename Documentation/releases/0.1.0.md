# KaitoFinder 0.1.0

最初のリリースです。macOS 26 以降、Apple Silicon 専用。

## できること

- ZIP / 7z / tar（gz・bz2・xz）/ LHA の作成・追加・削除・改名・パスワード設定と取り消し。
- RAR、ISO 9660、cpio、ar / deb、xar / pkg、CAB、RPM、StuffIt / StuffIt X、Zstandard、LZ4、lzma、compress など多くの形式の閲覧と展開。
- Finder と同じ操作感: ドラッグで取り出し・取り込み、Quick Look、右側のプレビュー、タブ、名称変更、サービスメニューからの圧縮・展開。
- 展開時の安全対策: パス検査、quarantine の伝播、上書きしない出力、進捗と取り消し。
- 26 言語の UI。

## 更新

「設定 › アップデート」からの自動確認と、署名付きの更新配信（Sparkle）。

## 注意

- 動画・音声のサムネイル、アイコン / カラム表示は未対応です。
- 4 GiB を超える項目や 64 GiB を超える書庫も扱えますが、圧縮 tar は開くときに内側の tar を一時展開します（空き容量に注意）。
