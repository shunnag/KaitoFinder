# KaitoFinder 0.10.5

2026-10-26 の監査検査で確認された 2 件の安全性の問題を直しました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.17.0 / GyoshukuKit 0.14.0 / Sparkle 2.10.1 を同梱。

## 修正

- **一括展開で作られる包み folder に、アーカイブの隔離属性（quarantine）を付けるようにしました。** 中身のファイルには
  付いていたのに包み folder 自身には付かず、アーカイブのファイル名によっては、隔離属性のない `.app` の root を
  組み立てられる状態でした。
- **置き換えの確認ダイアログの見出しに、アーカイブ内の名前をそのまま表示しないようにしました。** 名前に改行を
  含めると、見出しの先頭に偽の文を差し込み、本物の「置き換えますか？」を下へ押し下げられる状態でした。
  アーカイブ由来の名前を含む説明文も 1 行に畳みます。

## 同梱ライブラリの変更

- **KaitoKit 0.17.0**: 暗号化アーカイブのパスワード確認・展開で、鍵の導出に使う計算量に上限を設けました
  （7z / RAR5 / StuffIt X）。細工されたアーカイブに任意のパスワードを 1 度入れるだけで CPU を使い切らせる
  問題を防ぎます。鍵の導出は途中で取り消せるようになりました。別のパスワードを入れ直すと上限は戻ります。
- **GyoshukuKit 0.14.0**: アーカイブへ追加・改名する名前で、`/` 区切りの成分が 1,024 個を超えるものを拒否します。
  従来は作成できましたが、作ったアーカイブを読み戻せませんでした。
- **Sparkle 2.10.1**: 更新機構の不具合修正（リリースノートの参照先の空白処理、NFC のパスにある更新の適用時期）。

アーカイブの一覧・プレビュー・展開・作成・更新の動作は 0.10.4 と同じです。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開が
  できなくなることがあります。以前の版からある問題で、ウインドウを開き直すと直ります。今後の版で修正します。

## English

Fixes two safety problems found in the 2026-10-26 audit. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.17.0 / GyoshukuKit 0.14.0 / Sparkle 2.10.1.

### Fixed

- **The wrapper folder created by batch extraction now carries the archive's quarantine attribute.** The files inside
  received it, but the wrapper folder itself did not, so depending on the archive's file name an `.app` bundle whose
  root lacked the quarantine mark could be assembled.
- **The replace-confirmation dialog no longer shows the name from inside the archive verbatim in its headline.**
  A name containing newlines could insert a fake line above it and push the real "Replace?" question down.
  Explanatory text that includes archive-supplied names is folded to a single line as well.

### Bundled library changes

- **KaitoKit 0.17.0**: key derivation for encrypted archives is now bounded (7z, RAR5, StuffIt X), so a crafted
  archive can no longer burn CPU without limit after a single password attempt. Derivation is cancellable, and
  entering a different password replenishes the budget.
- **GyoshukuKit 0.14.0**: names with more than 1,024 `/`-separated components are rejected when adding or renaming.
  Such archives could be written before but not read back.
- **Sparkle 2.10.1**: upstream fixes to the update mechanism.

Listing, preview, extraction, creation and updating behave as in 0.10.4.

### Known issue

- After an open archive is renamed or moved in Finder or elsewhere, preview, Quick Look and extraction in its window
  may stop working. This problem predates this version; reopening the window fixes it. It will be fixed in a
  future version.
