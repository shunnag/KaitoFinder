# KaitoFinder 0.10.0

設定の「圧縮」を形式ごとのタブに整理し、各方式の説明と標準に戻すボタンを加えました。並列数と電力の設定は新しい「パフォーマンス」タブに移しました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.14.1 / GyoshukuKit 0.11.0 / Sparkle 2.10.0 を同梱。

## 新機能・変更

- 設定の「圧縮」を ZIP・7z・tar・LHA のタブに分けました。最初は「新規アーカイブの既定フォーマット」に対応するタブを開きます。保存済みの設定はそのまま引き継ぎます。
- 圧縮方式・フィルタ・圧縮レベルなどにポインタを置くと、内容とおすすめを説明するようにしました。選んでいる圧縮方式の説明は、メニューの下にも 1 行で表示します。
- 圧縮方式とフィルタのメニューで、標準の項目に「（標準）」と表示するようにしました。
- 各形式のタブに「標準に戻す」ボタンを加えました。その形式の設定だけを標準に戻します。すでに標準のときは押せません。
- 「圧縮の並列数」「電力の使用方針」「速さを優先する」を新しい「パフォーマンス」タブに移しました。電力の使用方針は圧縮と展開の両方に使います。
- 設定のタブを切り替えると、ウインドウが内容に合わせて滑らかに伸び縮みするようにしました。上端の位置は変わらず、表示中の項目も動きません。「視差効果を減らす」がオンのときは、すぐに切り替えます。

## English

Reorganized the Compression settings into per-format tabs with descriptions of each option and a Restore Defaults button, and moved the thread and power settings to a new Performance tab. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.14.1 / GyoshukuKit 0.11.0 / Sparkle 2.10.0.

### New and changed

- The Compression settings are now split into ZIP, 7z, tar, and LHA tabs. Settings opens on the tab for the default format for new archives. Existing settings are kept.
- Hovering over compression methods, filters, levels, and other options shows what they do and which to choose. The description of the selected method is also shown on one line below the menu.
- The standard item in the compression method and filter menus is now marked “(standard)”.
- Each format tab has a Restore Defaults button that resets only that format's settings. It is unavailable when the settings are already the defaults.
- Compression threads, Power usage, and Prefer speed moved to a new Performance tab. Power usage applies to both compression and extraction.
- Switching settings tabs now smoothly resizes the window to fit the content. The top edge stays in place and visible controls do not move. With Reduce Motion on, tabs switch immediately.
