# KaitoFinder 0.5.2

同梱する書庫読み取りエンジンを **KaitoKit 0.12.1** に更新しました。LHA のメタデータ解析を効率化し、書庫入力・tar の解析と編集用データの扱いを整理しています。読み取り結果と公開 API の互換性を保っています。

GyoshukuKit 0.7.0、Sparkle 2.10.0 を同梱しています。

## English

Updated the bundled archive reader to **KaitoKit 0.12.1**. LHA metadata parsing is more efficient, and archive-input, tar-parsing, and editing-layout responsibilities have been reorganized. Reading results and public APIs remain compatible.

Includes GyoshukuKit 0.7.0 and Sparkle 2.10.0.
