# KaitoFinder 0.3.0

分割アーカイブの編集と保存方法の選択に対応しました。macOS 26 以降、Apple Silicon 専用。

## できること

- 7z、tar、tar.gz、tar.bz2、tar.xz、LHA、ZIP の番号付き分割アーカイブ（`.7z.001` など）の編集。全巻を書き直し、同じ巻サイズで分割し直します。
- 新しい設定「保存時にまとめて書き込む」を選んでから開くと、編集を保存時にまとめて反映できます。保存までは原本を変えず、変更を取り消せます。
- 「別名で保存…」に「分割:」を追加。「しない」、元と同じ巻サイズ、「サイズを指定…」から選んで保存できます。
- rpm パッケージ（rpm 6 など）の中のファイル一覧表示。
- DMG / HFS+ の decmpfs 圧縮ファイルの展開・プレビューと、旧 GNU sparse（`S` 型）を含む tar の閲覧・展開。

## 更新

- KaitoKit 0.9.0 / 0.10.0 の改善を反映しました。7z の Deflate64 と、WIM の XPRESS の 4〜64 KiB のチャンク（2 の累乗）に対応しました。
- 番号付きの巻をアプリ内から文書として開けるようになりました。途中の巻を選んでも入口の巻があればセット全体を開き、外部変更の検査は全巻を対象にします。
- 0.2.0 で分割セットの最初の巻だけを書き換え、他の巻と食い違わせる不具合を修正しました。既に壊れたセットを修復する機能はありません。
- 分割セットの書き込み途中で異常終了した場合、次回起動時・ボリュームの再接続時・開き直すときに、保存記録と巻の内容から保存の完了または元の状態への復元を試みます。判断できない場合は何も削除せず保留します。

## 注意

- 既定は従来どおり「すぐに書き込む」です。このモードでの分割セットの編集は巻サイズが揃ったものに限り、取り消せないため編集のたびに確認します。
- 巻サイズが揃っていないセットは「保存時にまとめて書き込む」で編集し、保存時に巻サイズを選びます。
- FAT / exFAT、ネットワークボリューム、同期フォルダ（file provider）上の分割セットの保存は既定では拒否します。保存先ごとの同意で許可でき、同意は別の保存先には引き継がれません。
- ZIP 本来の分割（`.z01 … .zip`）は引き続き読み取り専用です。
- DMG の ADC / APFS、decmpfs の一部方式、tar の star / Solaris sparse は引き続き未対応です。
