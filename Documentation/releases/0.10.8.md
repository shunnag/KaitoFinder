# KaitoFinder 0.10.8

旧 RAR と分割書庫の対応を拡げました。macOS 26 以降、Apple Silicon 専用。

KaitoKit 0.20.0 / GyoshukuKit 0.16.0 / Sparkle 2.10.1 を同梱。

## 改善

- **RAR4 の古い圧縮方式を展開できるようになりました。** unpack version 15 / 20 / 26 の adaptive Huffman + LZ77、version 20 / 26 の音声ブロックと solid 書庫に対応します。solid 書庫内の分割 member と、ENDARC を省略した分割巻も展開できます。
- **RAR 1.3 / 1.4 の `RE~^` 書庫を展開できるようになりました。** stored・Unpack15 圧縮・solid・旧暗号（ASCII password）・archive / file comment に対応します。
- **RAR 1.3 / 1.4 の分割書庫と SFX に対応しました。** `.rar` / `.r00` 形式では stored・圧縮・solid 分割を展開し、巻をまたいで辞書と adaptive Huffman 状態を引き継ぎます。`RSFX` marker と MZ 画像サイズを検証した `.exe` 先頭巻と `.r00` の組み合わせも開けます。

アプリの操作方法、編集・保存の仕組みは 0.10.7 と同じです。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開が
  できなくなることがあります。以前の版からある問題で、ウインドウを開き直すと直ります。今後の版で修正します。
- アプリのコーデック辞書の上限は 1 GiB です。RAR5 compression version 1 の書庫のうち、これを超える実確保量が必要なものは
  現行のアプリ設定では展開できません。KaitoKit の API で上限を引き上げた場合の対応であり、アプリ側の上限緩和は今後の課題です。
- custom RAR VM、RAR 1.3 / 1.4 の Data からの継続巻解決・ASCII 以外の password、CAB Quantum は引き続き未対応です。

## English

Expanded support for legacy RAR compression and split archives. Requires macOS 26 or later and Apple Silicon.

Includes KaitoKit 0.20.0 / GyoshukuKit 0.16.0 / Sparkle 2.10.1.

### Improvements

- Extract RAR4 unpack versions 15 / 20 / 26, including adaptive Huffman + LZ77, audio blocks in versions 20 / 26, solid archives, split members in solid groups, and volumes without an ENDARC marker.
- Extract RAR 1.3 / 1.4 `RE~^` archives with stored and Unpack15 compression, solid state, legacy encryption for ASCII passwords, and archive / file comments.
- Open RAR 1.3 / 1.4 `.rar` / `.r00` volumes with stored, compressed, and solid split members while preserving the dictionary and adaptive Huffman state across volumes. Verified `RSFX` and MZ layouts also support a `.exe` first volume followed by `.r00`.

The user interface and editing / saving model are unchanged from 0.10.7.

### Known issues

- After an open archive is renamed or moved in Finder or elsewhere, preview, Quick Look and extraction in its window
  may stop working. This problem predates this version; reopening the window fixes it. It will be fixed in a future version.
- The app's codec dictionary limit is 1 GiB. RAR5 compression version 1 archives that need a larger allocation cannot be extracted
  with the current app settings. KaitoKit supports them when its API limits are raised; relaxing the app's limit remains future work.
- Custom RAR VM programs, continuation of RAR 1.3 / 1.4 volumes from Data, non-ASCII passwords for these old archives, and CAB Quantum remain unsupported.
