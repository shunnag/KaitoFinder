# M0 検証記録（2026-09-10）

## 実装範囲

- AppKit の `@main` delegate、`NSDocumentController`、読み取り専用 `NSDocument`。
- reader は `ArchiveSession` actor が所有し、UI には `[ArchiveEntry]` だけを渡す。
- `pathComponents` から仮想フォルダを合成し、実ディレクトリと統合する。
  先頭の `./` を表示上除き、元の entry と `..` は保持する。
- 7 列の `NSOutlineView`、列の並べ替え・幅の保存、再帰サイズ、UTType のアイコン。
- 日本語を開発言語とする日英 String Catalog。
- M1 以降の機能は未実装。

## ビルド

Xcode 27.0（27A5252f）、macOS 27 SDK、arm64、deployment target 26.0。
アプリのビルドと `build-for-testing` は成功。Swift のコンパイル警告はない。
警告抑制フラグは設定していない。
Xcode 自体からは CoreSimulator 接続、型検出、および
`Metadata extraction skipped, no AppIntents.framework dependency found` の診断が出る。

この実行環境では既定キャッシュへの書き込みと子サンドボックスの起動が拒否されるため、
通常のコマンドそのままでは package 解決に失敗する。以下の実行時オプションで
キャッシュとビルド成果物をリポジトリ内へ置いた。これらはプロジェクト設定には加えていない。
`-disable-sandbox` は Swift コンパイラの子プロセス用であり、実行環境の制限は維持される。

```sh
CFFIXED_USER_HOME="$PWD/build/User" \
XDG_CACHE_HOME="$PWD/build/Cache" \
CLANG_MODULE_CACHE_PATH="$PWD/build/ModuleCache" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/build/ModuleCache" \
xcodebuild -project KaitoFinder.xcodeproj -scheme KaitoFinder \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath build/DerivedData \
  -clonedSourcePackagesDirPath build/SourcePackages \
  -IDEPackageSupportDisableManifestSandbox=YES \
  'OTHER_SWIFT_FLAGS=$(inherited) -disable-sandbox' build
```
