## このリリースで配布する変更

- 名前の文字コード判定、ZIP64、tar / LHA / RAR のヘッダー走査、ネットワークボリュームからの読み取りを改善。
- RAR5 solid、DMG、WinZip AES、BZip2、PPMd、RAR、LZMA / LZMA2、Deflate64 などの展開を高速化。
- ZIP AES の鍵導出と暗号化、7z の一括追加、tar の出力バッファーを改善。ZIP で無圧縮格納する圧縮済み拡張子を拡充。
- 圧縮 tar・単一ファイルの staging で、展開後の大きさが分かる場合のメモリと I/O を削減。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開が
  できなくなることがある。0.10.5 と同じく、ウインドウを開き直すと回復する。今回の依存更新による修正対象外。
