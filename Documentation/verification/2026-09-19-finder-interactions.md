# Finderに合わせた名称変更と操作の確認（2026-09-19）

## 実装

- 選択済みの名前を一度クリックすると、macOSのダブルクリック間隔が過ぎてから名称変更を開始する。最初の選択クリック、ダブルクリック、アイコン、名前の右の余白、別の列、修飾キー付きクリック、複数選択からのクリック、ドラッグでは開始しない。
- 背景ウインドウを前面にするためのクリックは名称変更に使わない。選択、検索、ソート、フォーカス、コンテキストメニュー、設定、ウインドウの変更で古いクリック予約を取り消す。
- ファイルは最後の拡張子を残して名前を選択し、フォルダは名前全体を選択する。ドットファイル・日本語・絵文字はUTF-16の選択範囲を検証する。確定・検証・取消し・Undoは既存の名称変更と同じ経路を使う。
- 設定 › 一般の「選択した名前をクリックして名称変更（Finderと同じ）」を追加。新規・既存ユーザーとも未設定ならオン。オフを保存すれば再起動後も従来のクリック操作となる。開いている書庫にも即時反映し、Returnと名称変更メニューは常に使える。26言語を追加。
- ⌘↓と⌘Oで選択ファイルを開き、フォルダなら一覧を広げる。⌘↑で書庫内の親を選択する。書庫の最上位から外には移動しない。
- クイックルックは修飾キーなしのSpaceで開く。編集中のSpace、⌘Space、⌃Spaceなどを横取りしない。
- 書庫の変更処理中は、プレビュー表示のメニュー・ツールバー・アクションを同じ規則で無効にする。

`ArchiveOutlineView`は、イベントを変更せずにローカルモニターでクリックを観測する。mouseDown/mouseUpの上書きでmacOSの標準ジェスチャー処理を無効にしない。ドラッグ開始時も予約を解除する。モニターはビューのウインドウ移動と破棄時に解除する。

## Finderとの比較

Returnによる名称変更と複数項目の名称変更は[Appleの名称変更ガイド](https://support.apple.com/ja-jp/guide/mac-help/mchlp1144/mac)、Space・⌘O・⌘↑／↓・⇧⌘N・⌘Zなどは[Appleのショートカット一覧](https://support.apple.com/ja-jp/102650)を参照した。

| 操作 | 確認・変更 |
| --- | --- |
| 名前の再クリック／Return／Escape | クリック開始を追加。拡張子を残す選択、確定、取消し、Undoを確認 |
| ダブルクリックとドラッグ | 改名と競合しない。別ウインドウ・別タブへの100ファイルとフォルダのドラッグを再検証 |
| ⌘O／⌘↓／⌘↑ | フォルダを開くメニューの有効状態を修正し、上下のショートカットを追加 |
| Spaceと文字入力 | 修飾キー付きSpaceの誤動作を修正。名前の入力中はクイックルックを起動しない |
| 複数選択、新規フォルダ、削除、Undo、同名衝突 | 既存の実操作・書庫の内容・Undoのテストを実行 |
| タブのクリック、ドラッグ中のタブ切り替え | 標準タブと複数書庫間コピーのテストを実行 |
| 右プレビューと設定画面 | 初期状態オフ、表示切り替え、選択追従、26言語の設定レイアウトを確認 |

残る主な仕様上の相違点・未実装機能も確認した。フォルダはFinderのように現在の場所を置き換えず、書庫全体の階層一覧で開く。複数項目の一括名称変更、⌘Dによる複製、⌥⌘Vによる移動は未実装。別書庫へのドラッグはコピーで、書庫内の削除はFinderのゴミ箱ではなく書庫のUndoで戻す。これらは今回のクリック設定では変更しない。
