# 右側プレビューの検証（2026-09-19）

「表示 > プレビューを表示」、⇧⌘P、ツールバー右端のボタンから、選択ファイルの Quick Look を右側に表示する。新しく開く書庫ではオフ。表示状態と幅は各ウインドウ・タブで独立している。

一覧とプレビューは標準の `NSSplitViewController` で分割する。境界をドラッグして幅を変えられ、表示の切り替えでウインドウの大きさは変わらない。幅保持の優先度は251とし、境界のドラッグを妨げない。長い案内文は領域内でスクロールできる。

右側の抽出要求は、Spaceで開くQuick Lookパネルや外部アプリで開く要求と独立している。一時領域の所有者が子の要求を保持し、表示世代の変更でUIが子を手放した場合も、取消し後の書き込み完了とコピーの回収を待ってから一時領域を削除する。暗号化項目の選択だけではパスワードを要求しない。

## 自動テスト

```sh
python3 Tools/verify_preview_sidebar.py
```

プレビューだけを再検証する場合は `--preview-only` を指定する。検証にはロックされていないGUIセッションと、検証用ウインドウの撮影・マウス操作の権限が必要。通常のアプリとは異なるUUID付きbundle IDを使用する。

最終実行は90件成功、失敗・スキップともに0件。新規の `ArchivePreviewSidebarTests` は13件。

- 選択変更、複数選択、フォルダ、検索、ソート、書庫編集後の再読み込み
- 暗号化・未対応・不完全な項目、失敗の領域内表示
- 非表示・終了時の取消し、遅れて完了した結果の破棄、子の要求を手放した後の後始末
