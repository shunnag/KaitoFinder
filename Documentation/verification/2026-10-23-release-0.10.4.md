# 2026-10-23 リリース 0.10.4 (18) の公開結果

KaitoKit 0.16.0 と GyoshukuKit 0.13.0 を同梱する KaitoFinder のリリース。KaitoFinder のコードは 0.10.3 から変えていない。KaitoKit 0.16.0 は非ローカル volume 上の入力を高遅延として扱い（`inputLatency` 既定 `.automatic`）、solid 7z（LZMA2）の事前走査の省略、RAR4 / RAR5 のヘッダ走査の適応窓、単独で開いた分割 RAR の続き巻の早期拒否が、KaitoFinder の既定の読み取り設定（`ReaderOptions.kaitoFinder`）にそのまま効く。KaitoFinder は `rar5QuickOpenPolicy` を設定しないため、RAR5 Quick Open（既定 `.never`）は使わない。GyoshukuKit 0.13.0 は KaitoKit 0.16.x への追従だけ。
