# 2026-10-21 リリース 0.10.3 (17) の公開結果

0.10.2 で入れた閲覧用 ArchiveReader の `FileAccessPolicy.bounded` を取り消し、0.10.1 と同じ persistent に戻した KaitoFinder のリリース。KaitoFinder は 0.10.0 から起動時に RLIMIT_NOFILE を 10240 へ上げており（`AppDelegate.raiseFileDescriptorLimit`）、FD の上限対策は不要だった。bounded は退避したハンドルを開いた時点の親パスと葉名で開き直すため、移動を追跡したセッションでも読み取りが ENOENT になっていた。同梱の KaitoKit 0.15.0・GyoshukuKit 0.12.0 は据え置き。
