## このリリースで配布する変更

- 不正な LZ4 ファイルの並列検証を最初の失敗で打ち切り、キャンセルもブロックごとに確認する。部分出力とエラーの順は従来の直列経路で再現する。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開ができなくなることがある。以前の版からある問題で、今回の対象外。
- コーデック辞書の上限は既定で 1 GiB、物理メモリ 32 GiB 以上の Mac では 8 GiB を選べる。選択した上限を超える実確保が必要な RAR5 compression version 1 書庫は展開できない。
- custom RAR VM、RAR 1.3 / 1.4 の Data からの継続巻・ASCII 以外の password、CAB Quantum は引き続き未対応。
