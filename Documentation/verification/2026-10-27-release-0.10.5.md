## このリリースで配布する修正

- 一括展開が作る包み folder に書庫の `com.apple.quarantine` を継承する。中身には印が付くのに包み folder 自身には
  付かず、書庫のファイル名由来の名前を持つ `.app` bundle の root を無印で組み立てられた。
- 置き換え確認ダイアログの太字見出しと alert の説明文で、書庫由来の名前を 1 行に畳む。名前に改行を入れると
  見出しの先頭行を差し替え、破壊的操作の問いを下へ押し下げられた。

判定表と退けた主張は [2026-10-26-security-audit.md](2026-10-26-security-audit.md) にある（45 agent の読解と
敵対的反証 2 観点で 68 件を判定し、確認されたのはこの 2 件）。
