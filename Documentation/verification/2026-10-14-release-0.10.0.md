# 2026-10-14 リリース 0.10.0 (14) の公開結果

設定の「圧縮」を ZIP・7z・tar・LHA のタブに分け、各方式の説明（ツールチップと 1 行の説明）、標準の項目の「（標準）」表示、形式ごとの「標準に戻す」ボタンを加え、並列数と電力の設定を「パフォーマンス」タブに移した KaitoFinder のリリース。設定のタブ切り替えでは、ウインドウの上端と表示中の項目を動かさずに下端だけを伸縮する。KaitoKit 0.14.1 / GyoshukuKit 0.11.0 は前回と同じ。
