## このリリースで配布する変更

- RAR4 unpack version 15 / 20 / 26 の adaptive Huffman + LZ77、version 20 / 26 の音声ブロック、solid、solid 内の分割 member、ENDARC 省略巻に対応。
- RAR 1.3 / 1.4 の stored・Unpack15・solid・旧暗号（ASCII password）・archive / file comment に対応。
- RAR 1.3 / 1.4 の old `.r00`、solid 分割、検証済み SFX `.exe` + `.r00` に対応。SFX `.exe` は KaitoKit が書庫として検出した場合だけ文書型にし、通常の実行ファイルは従来どおり拒否する。いずれも実行しない。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開ができなくなることがある。以前の版からある問題で、今回の対象外。
- アプリのコーデック辞書の上限は 1 GiB。これを超える実確保が必要な RAR5 compression version 1 書庫は、現行設定では展開できない。
- custom RAR VM、RAR 1.3 / 1.4 の Data からの継続巻・ASCII 以外の password、CAB Quantum は引き続き未対応。
- ローカルの native drag は 0.10.7 と同じ既知の失敗で、CI では成功している。tab hover は検証用 app のフォーカス影響で、個別再実行では成功している。
