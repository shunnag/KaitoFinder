## このリリースで配布する変更

- 7z / XZ の RISC-V filter を展開できる。JAL、AUIPC と後続命令の対、縮小命令を含む入力に対応する。
- RAR4 / RAR5 の分割自己解凍書庫を開ける。`.partN.exe`、RAR4 の `.exe` / `.r00` 形式を含む。
- KaitoKit は RAR5 compression version 1 の 80 distance symbols、4 GiB を超える非2の累乗辞書、長い距離の上位 8 bit を持つ並列 token に対応する。
- RAR5 version 1 の 5 GiB 実書庫 2 種類で原本と全 byte が一致した。5 GiB の非2の累乗辞書は実確保 8 GiB となり、6 GiB entry / 8 GiB dictionary の指定で展開を検証した。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開が
  できなくなることがある。0.10.6 と同じく、ウインドウを開き直すと回復する。今回の依存更新による修正対象外。
- KaitoFinder は KaitoKit 既定の 1 GiB のコーデック辞書上限を維持する。これを超える実確保が必要な RAR5 version 1 書庫は
  現行のアプリ設定では展開できない。KaitoKit API で上限を引き上げた場合の対応であり、アプリ側の安全な上限緩和は
  `cooViewer-aayi` として継続する。
- CAB Quantum は実 fixture と生成器を確保したが、許可された算術 codec 仕様が未確保のため今回の対象外。
  `cooViewer-c1vj.6` として継続する。
