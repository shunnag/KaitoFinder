## 手順で気付いたこと

- GitHub Actions の macOS runner は 1 run あたり約 1 時間待たされた。重ねて push した main の run は取り消して PR の run を先に通した。
- release notes の抽出で BSD sed は `1{/^$/d;}` と書く（`;` が無いと失敗する）。
- 自動 mode の分類器は `notarytool submit` を拒否した（前回と同じ）。公証と staple は利用者が自分の terminal で実行した。
