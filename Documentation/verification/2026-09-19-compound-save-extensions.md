# 保存時の複合拡張子の置き換え（2026-09-19）

## 実装

- 手入力した名前で形式を変更した場合、対応する書庫拡張子のうち最長のものを一つだけ置き換える。
  `report.tar.gz` → `report.tar.xz` → `report.zip`となる。
- 大文字と短縮形も認識し、形式変更後は選択形式の標準拡張子に揃える。
  形式を変更しない場合は、手入力した短縮形や大文字を保持する。
- 名前の本体のドット、日本語・絵文字、ドットファイル、元ファイルの拡張子は残す。
  `photo.jpg` → `photo.jpg.tar.xz`、`source.zip.zip` → `source.zip.tar.gz`。
- 初期候補の生成、新規圧縮と形式変換の区別、拡張子の検証は従来の経路を使う。

標準保存パネルの`nameFieldStringValue`はconfiguration phaseでしか設定できない。
明示した名前の形式変更では同じパネルを一度閉じて再構成する。再表示を伴う制約がある。
表示中の名前setterや確定URLの書き換えは使わず、画面と標準の上書き確認を実際の保存名に揃える。
内部のキャンセルは`ArchiveSavePanel.begin`内で扱い、呼び出し元には最終の保存・キャンセルだけを返す。

明示した複合拡張子には末尾の圧縮型を指定し、AppKitによる拡張子の二重補完を防ぐ。
名前から拡張子を消した場合は、`isExtensionHidden`の公開KVO通知で完全な拡張子の補完へ戻す。
名前変更の通知時点ではhiddenの値が更新前なので、この順序を実入力で検証している。
タイマー、非公開API、アクセシビリティによる製品側の名前編集は使用しない。

保存先・タグ・暗号化入力のビューと値を引き継ぐ。上端（シートでは中央）と幅を保ち、
入力欄の増減とAppKitの最小サイズに合わせて高さを決める。一覧付きパネルの再表示で
標準の最小高さが増えた場合は、その制約を尊重する。再表示時のウインドウアニメーションは抑止する。
Taskの取消しと親ウインドウの終了では再表示を止める。
