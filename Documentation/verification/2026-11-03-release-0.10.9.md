## このリリースで配布する変更

- 関連付けから書庫を開くときは、起動時のウェルカム表示設定がオンでもようこそを表示せず、表示済みの場合は閉じる。書庫を開く処理は従来どおり。
- LZ4 の独立ブロックを検証後に並列復号し、text は M4 Max / mini baseline の 0.8686 / 0.7664 倍、50,000 小ファイルは 0.9400 / 0.8979 倍。
- Deflate64 の bit 状態と Huffman 表を最適化し、ZIP / 7z で baseline の約 0.92〜0.93 倍。
- CAB LZX の高速 Huffman 表と block 参照により、実 product.cab で baseline の 0.4535 / 0.4386 倍。
- RAR15 の solid 状態バッファを固定長化し、single thread で baseline の 0.7778 / 0.7340 倍。

## 既知の問題

- 開いているアーカイブを Finder などで名称変更・移動すると、そのウインドウでプレビュー・クイックルック・展開ができなくなることがある。以前の版からある問題で、今回の対象外。
- アプリのコーデック辞書の上限は 1 GiB。これを超える実確保が必要な RAR5 compression version 1 書庫は、現行設定では展開できない。
- custom RAR VM、RAR 1.3 / 1.4 の Data からの継続巻・ASCII 以外の password、CAB Quantum は引き続き未対応。
