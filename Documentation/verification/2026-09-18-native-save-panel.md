## 修正した問題

非表示パネルの名前と型のテストだけでは、表示中のXPC保存パネルの挙動を保証できなかった。
`nameFieldStringValue`は表示中に変更できず、複合拡張子の形式変更で
`review.tar.gz.tar.bz2`などの余分な拡張子が残った。確定したURLも重複していた。

- 許可する型を固定し、形式変更には公開の`currentContentType`を使う。
- 通常の候補では拡張子を隠し、形式に対応する`.tar.gz` / `.tar.bz2` / `.tar.xz`を生成する。
  型を先に設定し、初期名の末尾だけを隠すAppKitの挙動に合わせて名前を渡す。
- 入力元が`review.zip`なら、ZIPへの新規追加では`review.zip.zip`を候補にする。
  形式変換では元の書庫拡張子を置き換える。この二つを別々に実保存ボタンで検査する。
- LHAの候補は`.lzh`に揃え、手入力の`.lha`も保持する。
- 拡張子まで手入力した名前では、標準パネルが最後の拡張子を置き換える動作を使う。
  `report.tar.gz`からbzip2へ変更すると`report.tar.tbz2`、`report.zip`からgzipへ変更すると
  `report.tgz`になる。短縮形を使うことで、`.tar`の増殖と保存時の二重付与を避ける。
  変更後に名前を拡張子なしで入力し直しても、選択形式の短縮拡張子が付く。
  `gz` / `bz2` / `xz`だけを選ぶ方式ではこの再編集で`.tar`が不足するため採用しない。
  手入力済みの名前に対して、表示中のsetterや独自の後処理で保存先を変更しない。

下端までの余裕を確認し、収まらない場合は標準パネルに一覧領域の調整を任せる。
下端8 pt上で2回開閉し、シート全体と入力欄が収まる回帰テストを追加した。

遅延生成される画像表現の違いで不安定に失敗した。対象外の行に元のアイコンが保持されることを
確認するテストへ変更した。サムネイル生成、対象外の除外、パスワード・進捗・一時コピーの抑制は引き続き検査する。
