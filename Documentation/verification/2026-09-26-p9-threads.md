## 実装

- `ArchiveCompressionThreads` は既定0（自動）。読み取りは Bool でない整数の NSNumber の0または1...64だけを受け、
  不正値・未設定は0。setter も範囲外を0に戻し、全キーを保存した後の同期通知を一度だけ送る。
- `writerOptions(for:)` の switch の後で全7形式に並列数を写す。0は nil。
  P2-A の `additionPlacement`・`carriedTarOwnerIDs` を含め、他の field は維持した。
- `ArchiveHardware` に自動値 `max(1, min(processors, 8, Int(memory >> 30)))` と
  LZMA2 の見積り `(30 + 135 * threads) << 20` を置いた。GK の internal な式の写しである理由をコメントに記載した。
  `ArchiveSession.verify` はこの自動値を使う。展開、予約、保存結果の検証の並列度は変更していない。
- 設定の「圧縮」タブで `.DS_Store` 等の group の直後に popup と注記を追加した。
  項目は「自動（N）」と1...max(コア数, 保存値)。コア数より大きい保存値も表示・使用する。
  ハードウェアと翻訳 bundle は view model に保持し、通知による再表示でも維持する。
- 注記は `.memory` の ByteCountFormatter を使い、見積りが物理メモリの1/4を超えると注意文を追加しオレンジで表示する。
  最大項目の見積りと注意文を初期化時に幅360で測り、label の最小高さを確保する。
  popup の accessibility label は `row(_:control:)` の「圧縮の並列数:」。
- 作成・変換、開いている文書の即時編集・保存時保存・分割保存・別名保存、パスワードの変更は既存の options の経路を使う。
  次の書き込みから効くため、この設定に「次に開くアーカイブから有効」の注記は追加していない。
- `TestProcessSetup.autosaveKeys` と `AutosaveIsolationTests` の両方に新しいキーを追加した。
  README、計画の P9 行、次回リリースの文書も更新した。
